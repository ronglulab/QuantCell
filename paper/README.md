# Code for the figures and tables in the QuantCell paper

All scripts read their locations from `config.py`. Set three environment variables (or edit the defaults there):

| Variable | Contents |
|---|---|
| `QC_DATA` | The extracted Zenodo deposit (https://doi.org/10.5281/zenodo.23672666): `raw_image/`, `qupath_exports/`, `quantcell/` |
| `QC_EXTERNAL` | The external datasets, see below |
| `QC_OUT` | Output folder for intermediate results and figures |

External datasets (not redistributed; download from the original sources):

| Path under `QC_EXTERNAL` | Source |
|---|---|
| `colon/CRC_clusters_neighborhoods_markers.csv` | Schürch et al., Cell 2020 (colorectal cancer CODEX) |
| `cHL_1_MIBI/annotation_csv/cHL1_MIBI.csv` | MAPS, Shaban et al., Nat Commun 2024; Zenodo 10.5281/zenodo.10067010 |
| `cHL_2_MIBI/annotation_csv/1.csv` ... `6.csv` | same |
| `cHL_CODEX/annotation_csv/cHL_CODEX_annotation.csv` | same |

`inputs/` holds small published inputs used as-is: the Astir and AnnoSpat marker files for bone marrow, the MAPS authors'
marker lists for the cHL datasets, CELESTA's colon signature matrix, and the literature references for Table EV1.

## Environments
- QuantCell and all figure scripts: the environment in the main README (Python 3.11, scikit-learn 1.5.0, pandas 1.5.3, Matplotlib 3.7.1,
  LightGBM 4.6.0) plus SciPy, seaborn, tifffile and contourpy.
- Benchmarked methods, each in its own environment: astir 0.1.2, MAPS 1.0.0, AnnoSpat 1.0.0, and CELESTA (R 4.4.2 with
  zeallot, Rmixmod, spdep).
- Figure EV1 segmentation: cellpose 4.0.6 (Cellpose-SAM), ideally on a GPU.

## Running
`bash run_all.sh` runs everything in order; `bash run_all.sh figures` re-renders figures from existing results. Point
`PY`, `ASTIR_PY`, `MAPS_PY`, `ANNOSPAT`, `RSCRIPT` and `CELLPOSE_PY` at the environments above. The full run takes several
days of CPU time, mostly hyperparameter tuning (`bm_04`), the feature and marker analyses (`bm_06`, `bm_07`), MAPS, and the
external model comparison (`ext_01`). Long steps write checkpoints and resume.

Scripts are grouped by prefix: `bm_` bone marrow, `colon_`, `chl_`/`chl2_` lymph node, `ext_` external model comparison,
`bench_` benchmark summaries, `seg_` membrane-based segmentation, `spatial_` spatial features. `_common.py` holds the shared
classifier settings: set `QC_CLF=lgbm` for the LightGBM analyses (default random forest) and `QC_NAME` to switch project.

on other hardware.
